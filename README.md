# personal-setup
A collection of pre-built (by me) configurations for setting up my personal workflow. Only for linux.

# How to use
Run the script directly from the website (with arguments -y and --yes via `bash -s -- -y` or `bash -s -- -yes`)
```console
curl -fsSL https://raw.githubusercontent.com/DrakenGuard/personal-setup/refs/heads/main/setup.sh | bash
```
or
```console
wget -qO- https://raw.githubusercontent.com/DrakenGuard/personal-setup/refs/heads/main/setup.sh | bash
```
Download the script then run
```console
curl -fsSLO https://raw.githubusercontent.com/DrakenGuard/personal-setup/refs/heads/main/setup.sh 
bash script.sh
```
